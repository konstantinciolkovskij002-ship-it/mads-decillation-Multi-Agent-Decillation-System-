# MADS — Adaptive Multi-Agent Immune Architecture

**MADS** — это распределённая мультиагентная иммунная архитектура для больших языковых моделей.

Система не изменяет ядро LLM. Она строится **вокруг** модели как внешний иммунный слой.

---

## Что такое MADS

MADS — Multi-Agent Decillation System.

Основной принцип — **дециляция**: ложь не отбрасывается, а **схлопывается** через перекрёстный допрос независимыми агентами. Истина — то, что остаётся.

---

## Архитектура

Три гравитационных кластера:

| Кластер | Функция |
|---------|---------|
| **Защита** | Предотвращение деструкции |
| **Истина** | Достоверность и честность |
| **Контекст** | Память, адаптация, границы сессии |

Плюс **Институт Права**.

Всего агентов: **28** (v4.2.3)
